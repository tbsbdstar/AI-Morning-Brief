# AI早知道（AI-Morning-Brief）

每天定时搜罗全网的 **AI 动态、信息安全、产品经理** 三类资讯，剔除旧闻、跳转页、重复和软文，生成带日期和原文链接的中文早报，推送到邮箱、微信或企业微信。每一次检索、每一次打开网页都逐条留档，任何一条都能回查出处。

适合不想每天刷资讯、但又不想错过重要动态的人。

## 它是怎么做的

1. **检索与初选**：以无界面方式运行 [Claude Code](https://www.anthropic.com/claude-code)，只开放「网页检索」和「打开网页」两个工具（不能写文件，也不能执行命令）。它按栏目和关键词检索全网，逐条打开原文，核实发布日期和内容，然后打分精选。
2. **逐条留档**：每次检索、每次打开网页的前后，钩子都会把原始数据原样写成一个文件，存在 `logs/<日期>/run_<时间>/raw/`，同时生成一份可读版的检索日志。
3. **程序核验**：不依赖模型自觉，代码会再检查一遍，下面任一情况都会剔除：
   - 链接没在检索日志里出现过（防编造）
   - 早于栏目的时间窗（旧闻）
   - 是短链、搜索页、聚合页、标签页或首页
   - 近期已经推送过（链接相同或标题相似）
   - 原文打不开，又没有其他来源印证
   - 是自媒体消息，又没有独立印证
   - 重要性低于门槛
4. **成稿与推送**：生成推送版和留档版，各有 HTML 和 Markdown 两种格式。留档版带每条的溯源编号和完整的剔除清单。到点推送；如果生成失败，也会推一条失败通知。

## 功能

- **桌面窗口程序**：双击 `AI早知道.exe`，以独立窗口打开，没有地址栏和标签页，跟随系统深色/浅色模式。共六个页面：
  - **早报**：按日期翻看
  - **检索日志**：逐条看原始记录
  - **回查**：贴一个链接，查它从哪来、为什么入选或被剔除
  - **栏目与关键词**：改要找的内容
  - **推送与定时**：选推送方式、设定时间
  - **环境检查**：换电脑时逐项引导配置
- **栏目可配置**：每一栏可以设关注点、关键词、时间窗、条数、细分标签和写作要求，在界面里改，保存即生效。默认三栏：
  - AI 动态（近 24 小时）
  - 信息安全（近 24 小时）
  - 产品经理（近 7 天，分行业观察、方法与案例、AI 提效工具、新思路与创作四类）
- **多种推送方式**：邮件（推荐，HTML 排版，可以发给多人，每人单独一封）、Server酱、WxPusher、PushPlus、企业微信群机器人，可以同时选多个。
- **定时运行**：用 Windows 计划任务每天自动生成并推送。时间按配置里的时区（默认北京时间）换算成本机时间。
- **换电脑 / 移交**：一键导出移交包。「给自己」带上令牌和历史；「给别人」不带任何密钥和个人数据。

## 运行环境

- Windows 10 / 11
- Python 3.8 或更高版本（只用标准库，不用 pip 装任何东西）
- [Claude Code](https://www.anthropic.com/claude-code) 命令行，以及一个 Claude 订阅账号（Pro / Max / Team 等）。每天的检索靠它完成，一次大约 10–15 分钟。
- Microsoft Edge 或 Google Chrome（用来显示程序窗口，Windows 自带 Edge）

## 快速开始

1. 下载本仓库（Code → Download ZIP），解压到任意位置。
2. 双击 `launcher\build.bat`，生成 `AI早知道.exe`。它用 Windows 自带的 .NET 编译器，不用另外装任何东西。
3. 双击 `AI早知道.exe`，进入「**环境检查**」页，逐项完成：
   - **Claude Code**：没装的话点「安装」（通过 winget）。
   - **Claude 授权**：点「设置长期令牌」→「生成令牌」，在浏览器授权后，把 `sk-ant-` 开头的令牌粘贴回来，点「保存并验证」。令牌有效期一年，之后每天的运行不依赖账号登录状态。
   - **推送通道**：到「推送与定时」页勾选通道并填写，点「保存并发一条测试」。
   - **每日定时任务**：在「推送与定时」页设好时间，点「保存并安装」。
   - **桌面快捷方式**：点「创建」。
4. 想先看效果，点左下角「只生成，不推送」，大约 12 分钟后在「早报」页查看。

不想用窗口程序的话，也可以用命令行：

```
python run_brief.py --no-push                       只生成不推送
python run_brief.py --no-wait                       生成后立即推送
python run_brief.py --refinalize logs/<日期>/run_x   不重新检索，按新规则重新核验成稿
python run_brief.py --push-only 2026-11-13          把某天的早报再推一次
python 回查.py --url <链接>                          查一条链接的来龙去脉
```

## 推送方式怎么选

个人微信不开放给程序直接发消息，只能借第三方公众号或邮箱转达。2026 年各家的规则大致如下，以各家官网为准：

| 方式 | 收到的样子 | 限制 |
|---|---|---|
| **邮件**（推荐） | 完整 HTML 排版，永久留存；QQ 邮箱可配合手机 QQ 邮箱 App 或微信的邮箱提醒 | 需要在邮箱设置里开启 SMTP 并生成授权码 |
| Server酱 | 微信服务号卡片（免费版只显示标题），点开看全文 | 免费每天 5 条，只支持 Markdown |
| WxPusher | 推到 WxPusher App；进微信需绑定「微信 ClawBot」 | ClawBot 每次激活只管 24 小时、最多 10 条 |
| PushPlus | 微信公众号模板消息 | 需先付费实名认证 |
| 企业微信群机器人 | 企业微信内部群 | 进不了个人微信 |

## 目录

| 位置 | 内容 |
|---|---|
| `run_brief.py` | 主流程：检索 → 核验 → 成稿 → 推送 |
| `console.py` / `console.html` | 程序界面的后台和页面（只监听本机 127.0.0.1） |
| `push.py` | 各推送通道 |
| `loglib.py` / `hooks/log_tool.py` | 检索留档的合并、索引和钩子 |
| `prompt_template.md` | 给检索用的 Claude 的工作说明（去噪规则、真实性要求、写作要求） |
| `config.json` | 栏目、关键词、时间窗、定时、推送方式 |
| `secrets.example.json` | 密钥文件模板。实际的 `secrets.json` 由程序生成，**不会**提交到仓库 |
| `install_task.ps1` | 注册 Windows 计划任务 |
| `launcher/` | 启动器源码（C#）、图标和编译脚本 |
| `回查.py` | 命令行版回查 |

运行后会在本地生成 `logs/`（检索留档）、`briefs/`（每日早报）、`state/`（去重历史、令牌状态）和 `secrets.json`（令牌与推送密钥）。这些都已写进 `.gitignore`，不会被提交。

## 注意

- `secrets.json` 里是你的 Claude 令牌和推送密钥，相当于密码，不要外传，也不要提交到任何仓库。
- 每次运行会消耗 Claude 订阅额度。想省额度，可以在「栏目与关键词」页把模型换成 Sonnet。
- 定时任务只在一台电脑上安装，否则会重复推送。
- 早报内容由 AI 检索整理，程序已尽量保证链接真实、日期新鲜。重要信息请以原文为准。
